# FixHandPose
[![Thunderstore Badge](https://modding.resonite.net/assets/available-on-thunderstore.svg)](https://thunderstore.io/c/resonite/)

A [Resonite](https://resonite.com/) mod that fixes hand pose information for SteamVR drivers without skeletal input like Oasis WMR with the HP Reverb G2.

## Installation (Manual)
1. Install [BepisLoader](https://github.com/ResoniteModding/BepisLoader) for Resonite.
2. Download the latest release ZIP file (e.g., `nullobsi-FixHandPose-1.0.0.zip`) from the [Releases](https://github.com/nullobsi/FixHandPose/releases) page.
3. Extract the ZIP and copy the `plugins` folder to your BepInEx folder in your Resonite installation directory:
   - **Default location:** `C:\Program Files (x86)\Steam\steamapps\common\Resonite\BepInEx\`
4. Do the same for the Renderer directory.
5. Start the game. If you want to verify that the mod is working you can check your BepInEx logs.
